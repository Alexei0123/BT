# AniStreet
**AniStreet** – это современное веб-приложение для продажи и просмотра товаров, связанных с аниме и японской поп-культурой. Пользователи могут просматривать каталог товаров, добавлять понравившиеся позиции в корзину и оформлять заказы. В магазине представлены различные категории товаров, такие как фигурки персонажей, манга, одежда, аксессуары и другие тематические предметы.

Система разделена на публичную и приватную части. Публичная часть позволяет посетителям просматривать каталог товаров, искать интересующие позиции и знакомиться с их описанием. Приватная часть предоставляет зарегистрированным пользователям доступ к личному кабинету, где они могут управлять своим профилем и редактировать личные данные. Архитектура приложения построена по клиент-серверной модели: серверная часть обрабатывает запросы пользователей, управляет базой данных товаров и заказов, а клиентская часть отвечает за отображение интерфейса и взаимодействие с пользователем.

## Целевая аудитория:
+ Поклонники аниме и манги
+ Коллекционеры аниме-фигурок и тематических товаров
+ Пользователи, интересующиеся японской поп-культурой
+ Покупатели, ищущие уникальные подарки в аниме-стиле

## Ключевой функционал:
+ Регистрация пользователей
+ Авторизация и управление пользовательской сессией
+ Просмотр каталога аниме-товаров
+ Поиск и фильтрация товаров по категориям

+ Управление личными данными пользователя

___

## Структура приложения:
1. Главная (`/`) – публичная
2. Аутентификация (`/auth`) – регистрация, вход, восстановление пароля
3. Каталог (`/catalog`) – динамический список
4. Детальная страница товара (`/catalog/:id`) – динамическая
5. Личный кабинет (`/profile`) – приватный
6. Избранное (`/favorites`) – приватный
7. Корзина (`/cart`) – приватный
8. Админ-панель (`/admin`) – приватный (опционально)

___

## Технологический стек
### Frontend: Чистый JavaScript + HTML + CSS
HTML и CSS используются для создания структуры и стиля страниц: заголовки, карточки товаров, меню, кнопки, формы и футер.
JavaScript отвечает за отображение динамического контента на страницах: карточки товаров, списки избранного, обновление корзины и интерактивные элементы (клики, фильтры, поиск).
Навигация между страницами осуществляется через обычные ссылки и формы, а состояние пользователя хранится в сессии или локальном хранилище.

### Backend: Java + Spring Boot
Java выбран за возможность использовать один мощный язык  Java – и на серверной, и на клиентской стороне, что обеспечивает строгую типизацию, надёжность и масштабируемость разработки.
Spring Boot – мощный и удобный фреймворк для создания серверной части. Он обрабатывает HTTP-запросы, маршрутизацию страниц, работу с базой данных, хранение файлов, а также предоставляет готовые решения для безопасности, кэширования, асинхронной обработки и микросервисной архитектуры.

### База данных: MySQL
MySQL – надёжная и широко распространённая реляционная база данных с поддержкой сложных связей между таблицами и высокой производительностью при чтении данных.
Использование MySQL позволяет хранить информацию о пользователях, товарах, заказах и избранном, а также обеспечивает масштабируемость проекта и простоту репликации.

### Инфраструктура
Локальная разработка — backend приложения запускается локально на машине разработчика с использованием Spring Boot. Frontend размещён на GitHub Pages для тестирования клиентской части. Такой подход удобен для отладки, разработки и проверки функциональности без затрат на полноценный серверный хостинг.

## Интерфейс 
### Страница: Главная (`/`)
**Тип доступа:** публичный

**Основные блоки:**
1. **Шапка:** логотип, меню (Главная, Каталог, Избраное, Корзина, Войти(если авторизован то Профиль))
2. **Блок приветствия:** заголовок, краткое описание магазина, кнопка «Перейти в каталог»
3. **Секция «Новинки»:** 6 карточек товаров
4. **Футер:** контакты, информация о магазине
   
**Динамический контент:** карточки товаров новинок подгружаются из базы

### Страница: Аутентификация (`/auth`)
**Тип доступа:** публичный

**Основные блоки:**
1. **Шапка:** логотип, меню (Главная, Каталог, Избраное, Корзина, Войти(если авторизован то Профиль))
2. **Форма регистрации:** логин, имя пользователя, ключевое слово, пароль, подтверждение пароля
3. **Форма входа:** поля логина и пароль, кнопка «Войти»
4. **Восстановление пароля:** поля для ввода логина и ключевого слова
5. **Ссылки переключения:** вход / регистрация / восстановление пароля
   
**Динамический контент:** форма отправляет данные на сервер для проверки, вывод ошибок или успешного входа

### Страница: Каталог (`/catalog`)
**Тип доступа:** публичный

**Основные блоки:**
1. **Шапка:** логотип, меню (Главная, Каталог, Избраное, Корзина, Войти(если авторизован то Профиль))
2. **Фильтры товаров:** категория, цена, название
3. **Сетка товаров:** карточки товаров (изображение, название, цена)
4. **Пагинация:** бесконечный скролл 
   
**Динамический контент:** карточки товаров и результаты фильтрации подгружаются из базы

### Страница: Детальная страница товара (`/catalog/:id`)
**Тип доступа:** публичный

**Основные блоки:**
1. **Шапка:** логотип, меню (Главная, Каталог, Избраное, Корзина, Войти(если авторизован то Профиль))
2. **Информация о товаре:** изображение, название, цена, описание
3. **Кнопки действий:** добавить в избранное, добавить в корзину
   
**Динамический контент:** данные товара и подгружаются из базы

### Страница: Личный кабинет (`/profile`)
**Тип доступа:** приватный

**Основные блоки:**
1. **Шапка:** логотип, меню (Главная, Каталог, Избраное, Корзина, Войти(если авторизован то Профиль))
2. **Информация о пользователе:** логин, имя, ключевое слово
3. **Кнопка выхода из аккаунта**
   
**Динамический контент:** данные пользователя подгружаются из базы

### Страница: Избранное (`/favorites`)
**Тип доступа:** приватный

**Основные блоки:**
1. **Шапка:** логотип, меню (Главная, Каталог, Избраное, Корзина, Войти(если авторизован то Профиль))
2. **Список избранных товаров:** карточки товаров
3. **Кнопки действий:** удалить из избранного, перейти к товару
   
**Динамический контент:** карточки товаров подгружаются из базы

### Страница: Корзина (`/cart`)
**Тип доступа:** приватный

**Основные блоки:**
1. **Шапка:** логотип, меню (Главная, Каталог, Избраное, Корзина, Войти(если авторизован то Профиль))
2. **Список выбраных товаров:** список выбраных товаров с возможностью перейти на их страницу или удалить из корзины

3. **Управление товарами:** добавление, редактирование, удаление

**Динамический контент:** данные товаров и пользователей подгружаются из базы

## Схема данных 
### Модель User:
+ `id` — уникальный идентификатор пользователя
+ `username` — имя пользователя
+ `password_hash` — зашифрованный пароль
+ `login` — логин пользователя
+ `key_word` — ключевое слово
+ `role` — роль пользователя (USER или ADMIN)

### Модель Product:
+ `id` — уникальный идентификатор товара
+ `name` — название товара
+ `description` — описание товара
+ `price` — цена товара
+ `category` — категория товара (например: фигурки, постеры, одежда, манга)
+ `image_url` — ссылка на изображение товара

### Модель CartItem:
+ `id` — уникальный идентификатор позиции в корзине
+ `user_login` — логин пользователя, которому принадлежит корзина
+ `product_id` — идентификатор товара
+ `quantity` — количество данного товара в корзине (по умолчанию 1)
  
### Модель Favorite:
+ `id` — уникальный идентификатор записи в избранном
+ `user_login` — логин пользователя, которому принадлежит избранное
+ `product_id` — идентификатор товара, добавленного в избранное

## Ключевые эндпоинты 
### Users
+ `POST /users/register` — регистрация нового пользователя
+ `POST /users/login` — вход в систему
+ `GET /users/{login}` — получение информации о пользователе
+ `PUT /users/{login}` — обновление данных пользователя
+ `DELETE /users/{login}` — удаление пользователя

### Products
+ `GET /products` — получение списка товаров
+ `GET /products/{id}` — получение информации о товаре
+ `POST /products` — создание нового товара (только администратор)
+ `PUT /products/{id}` — обновление товара (только администратор)
+ `DELETE /products/{id}` — удаление товара (только администратор)

### Cart
+ `GET /cart/{userLogin}` — получение корзины пользователя
+ `POST /cart` — добавление товара в корзину
+ `PUT /cart/{id}` — изменение количества товара в корзине
+ `DELETE /cart/{id}` — удаление товара из корзины

### Favorites
+ `GET /favorites/{userLogin}` — получение избранных товаров пользователя
+ `POST /favorites` — добавление товара в избранное
+ `DELETE /favorites/{id}` — удаление товара из избранного

## Инструкция по установке

Для запуска проекта на локальной машине необходимо установить:
+ Java (JDK 17 или 21)
+ Spring Boot (3.5.13+)
+ MySQL Server (8.4+)
+ Git

### 1. Клонирование репозитория
```bash
git clone https://github.com/Alexei0123/BT
```
    
### 2. Настройка Бэкенда
1. Перейдите в папку бэкенда:
   ```bash
   cd ./backend
   ```
2. Подготовьте конфигурационный файл. Переименуйте:
   `src/main/resources/application.properties.origin` в `src/main/resources/application.properties`
   ```bash
   mv src/main/resources/application.properties.origin src/main/resources/application.properties
   ```
3. Откройте `src/main/resources/application.properties` и заполните все поля (настройки базы данных, параметры сервера) актуальными данными
4. Запустите бэкенд:
   ```bash
   ./mvnw spring-boot:run
   ```

### 3. Настройка Фронтенда
1. Откройте новый терминал и перейдите в папку фронтенда:
    ```bash
    cd ./docs
    ```
2. Установите зависимости:
    ```bash
    npm install
    ```
3. Запустите проект:
    ```bash
    npm run dev
    ```
